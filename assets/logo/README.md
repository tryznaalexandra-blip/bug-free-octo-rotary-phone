## Logo assets

Primary logo file:

- `salesforce-consultant-copilot-logo.svg`

This SVG is optimized for app icons and profile images:

- square canvas (`1024x1024`)
- dark blue gradient background
- stylized cloud + chat bubble + AI spark motif
- high-contrast white/cyan details

### Optional PNG export

If you need a PNG, you can convert the SVG with ImageMagick:

```bash
magick assets/logo/salesforce-consultant-copilot-logo.svg -resize 1024x1024 assets/logo/salesforce-consultant-copilot-logo.png
```
